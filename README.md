# StudyStack 📚

AI-powered study platform for college students.

## 🚀 Getting Started

### Frontend (Next.js)
1. `cd frontend`
2. `npm install`
3. `npm run dev`
4. Open [http://localhost:3000](http://localhost:3000)

### Backend (FastAPI)
1. `cd backend`
2. `python -m venv venv`
3. `source venv/bin/activate` (or `.\venv\Scripts\activate` on Windows)
4. `pip install -r requirements.txt`
5. `uvicorn app.main:app --reload`
6. Open [http://localhost:8000/docs](http://localhost:8000/docs)

## 🛠 Tech Stack
- **Frontend**: Next.js, TypeScript, Tailwind CSS, Supabase Client
- **Backend**: FastAPI, Python, pdfplumber, Tesseract
- **Database**: Supabase (PostgreSQL)
- **LLM**: Gemini / GPT-4o-mini
